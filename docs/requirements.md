# Requirements

## 概要

「あろはーず公式ホームページ」は、女性2人組の踊ってみたユニット「あろはーず」のファン向け公式サイトである。キャンディポップ、平成レトロ、遊べるテーマパーク感を前面に出し、プロフィール閲覧、動画紹介、交換日記、フォトアルバム、おみくじガチャ、隠し演出を1ページで提供する。

## 対象ユーザー

- あろはーずのファン
- 踊ってみた動画やユニット情報を見たい訪問者
- コメント投稿、占い、音楽プレイヤーなどの軽いインタラクションを楽しみたい訪問者
- お知らせ、日記、写真、ガチャ、手紙を更新する運営管理者

## 主要コンテンツ要件

### ローディング

- 初回表示時に全画面のローディング演出を表示する。
- ローディングはキャンディ同士の衝突、完了表示、進捗バーで構成する。
- 「あそびにいく！」ボタン押下でサイト本体へ遷移する。
- ボタン押下時に Web Audio API で開始音を再生する。

### 共通ナビゲーション

- 画面上部にスクロール追従のナビゲーションを表示する。
- ナビゲーションから以下のセクションへスムーズスクロールできる。
  - 映像 & 音楽シアター
  - プロフィール
  - 交換日記
  - ギャラリー
  - おみくじガチャ
- サイト上部には横スクロールするマルキー告知を表示する。
- フッターから運営管理室ログイン画面へ遷移できる。

### お知らせ

- ヒーロー下に運営室からのお知らせボードを表示する。
- 表示対象のお知らせがない場合はセクションを表示しない。
- お知らせをクリックすると詳細モーダルを表示する。
- お知らせ詳細では日付、タイトル、本文を表示する。
- お知らせは管理画面または Firebase/ローカルフォールバックのデータから取得する。

### ヒーロー

- メインビジュアル画像、公式ロゴ、キャッチコピー、説明文、SNSリンクを表示する。
- キャッチコピーは「踊って、笑って、あろはーず！」を中心にする。
- SNSリンクは YouTube、Instagram、ニコニコ動画、X を表示する。
- 公式ロゴはクリック可能で、複数回クリックすると隠しコンテンツを表示する。

### 隠しコンテンツ

- ロゴを5回クリックすると「シークレットおやつ部屋」モーダルを表示する。
- モーダル表示時にキャンディ雨の演出と効果音を再生する。
- モーダルには「すまいる」「きゃるめん」からの秘密メッセージを表示する。
- ユーザーはモーダルを閉じられる。

### 動画シアター

- 踊ってみた動画を3件表示する。
- 選択中の動画はレトロ TV 風の表示領域に YouTube iframe を埋め込んで表示する。
- 動画ごとに公開日、原曲名、メンバーコメント、推し数を表示する。
- ユーザーは動画を切り替えられる。
- ユーザーは動画ごとに「この動画を推す！」を ON/OFF でき、推し数は匿名UIDごとに1回だけFirestoreへ保存する。
- YouTube 埋め込み URL は通常の watch URL / embed URL / youtu.be URL から生成する。

### 8bit 音楽プレイヤー

- 2曲のオリジナル 8bit 風トラックを提供する。
- 再生、一時停止、次の曲へのスキップができる。
- Web Audio API で矩形波のメロディを生成する。
- 音量をスライダーで調整できる。
- プレイヤー内のハートボタンでいいね数を ON/OFF でき、匿名UIDごとに1回だけFirestoreへ保存する。

### プロフィール

- すまいる、きゃるめんの2名分のプロフィールを表示する。
- タブ切り替えで表示メンバーを変更できる。
- 各プロフィールには以下を表示する。
  - 日本語名、英語名
  - タグライン
  - 誕生日
  - 血液型
  - 好きなもの
  - 苦手なもの
  - 本人メッセージ
  - 署名風テキスト

### 交換日記

- Firebase/ローカルフォールバックから公開中の日記を取得して表示する。
- 日記一覧から対象日記を選択できる。
- 選択中の日記には日付、タイトル、著者、本文、相手からの返信、ステッカーを表示する。
- ファンは日記ごとに付箋コメントを投稿できる。
- 投稿フォームではニックネーム、付箋色、メッセージを入力する。
- ニックネームは20文字以内、メッセージは120文字以内とする。
- 投稿済みコメントは選択中の日記ごとに絞り込んで表示する。
- コメントは削除できる。
- コメントは Firestore の共有掲示板として保存し、全ユーザーに表示する。
- コメント削除は投稿者本人または管理者のみ可能とする。
- 日記が未登録の場合は空状態メッセージを表示する。

### フォトアルバム

- Firebase/ローカルフォールバックから公開中の写真を取得し、スクラップブック風のポラロイド一覧で表示する。
- カテゴリーは「すべて」「ダンス・イベント」「日常・おやつ」とする。
- 写真をクリックするとライトボックスを表示する。
- ライトボックスでは大きな画像、日付、カテゴリー、タイトル、説明文を表示する。
- ライトボックス内で前後の写真へ移動できる。
- 背景クリックまたは閉じるボタンでライトボックスを閉じられる。

### 管理画面

- `/admin` パスで運営管理室を表示する。
- Google アカウントログインに対応する。
- 管理者メールはコードに含めず、Firestore の `admins/{uid}` ドキュメントで管理者権限を判定する。
- 管理者権限がない Google アカウントでログインした場合はサインアウトし、権限なしエラーを表示する。
- Firebase がモック設定の場合は、テスト用の模擬管理者ログインを表示する。
- ログイン後、以下の管理タブを表示する。
  - ダッシュボード
  - お知らせ
  - 交換日記
  - フォト
  - ガチャ
  - 手紙
- ダッシュボードではページビュー、ガチャ回数、コンプリート数、ギャラリー閲覧、SNSクリック、動画クリックなどの日次統計を表示する。
- お知らせ管理では日付、タイトル、本文、公開状態を作成、更新、削除できる。
- 交換日記管理では日付、著者、タイトル、本文、返信、ステッカー、公開状態を作成、更新、削除できる。
- 写真アルバム管理では画像 URL、タイトル、日付、コメント、公開状態を作成、更新、削除できる。
- おみくじ管理では季節、タイトル、結果名、結果メッセージ、レアリティ、表示順、公開状態などを作成、更新、削除できる。
- コンプリート手紙管理では季節、タイトル、本文、著者、公開状態などを作成、更新、削除できる。
- 管理画面で保存した公開データは、公開画面のお知らせ、交換日記、フォトアルバムで利用される。
- Firebase が利用できない場合でもローカルストレージのフォールバックデータで動作確認できる。

### Firebase / Firestore

- Firebase Authentication を Google ログインに使用する。
- ファン向けガチャ保存には Firebase Authentication の匿名ログインを使用する。
- Firestore を以下の公開データと管理データの保存に使用する。
  - `photos`
  - `diaries`
  - `announcements`
  - `fortunes`
  - `letters`
  - `daily_stats`
  - `admins`
  - `users/{uid}/gacha/state`
- Firestore ルールでは一般ユーザーに公開データの読み取りを許可し、書き込みは管理者に限定する。
- 管理者判定は `admins/{uid}` の存在確認で行い、特定メールアドレスをルールに埋め込まない。
- `daily_stats` はテレメトリー記録用に作成/更新を許可する。
- `admins` コレクションの読み取りは本人または管理者に限定し、一覧取得と書き込みは管理者に限定する。
- `users/{uid}/gacha/state` は本人だけが読み書きできる。

### おみくじガチャ

- 1日1回だけおみくじを引ける。
- おみくじ結果は全6種類とする。
- ガチャ実行時は1.5秒の抽選演出を表示する。
- 抽選結果には以下を表示する。
  - 運勢レベル
  - タイトル
  - 説明文
  - すまいるコメントと5段階評価
  - きゃるめんコメントと5段階評価
  - ラッキーおやつ
  - ラッキーダンス
- 当日分の結果、最終抽選日、収集済み運勢、コンプリートレター宛名は匿名アカウントの Firestore データに保存する。
- 匿名ログインや Firestore 保存が使えない場合は、従来通り `localStorage` に保存する。
- 既存の `localStorage` 保存データがある場合は、匿名アカウント初期化時に Firestore の保存状態とマージする。
- 当日に再訪問した場合は同日の結果を復元し、再抽選を制限する。
- 結果カードは PNG 画像としてダウンロードできる。
- 全6種類を1回以上集めると、コンプリートレターを開ける。
- レターを開く前に訪問者名を登録できる。
- 訪問者名は15文字以内とし、`localStorage` に保存する。
- テスト用にガチャ記録を初期化する操作を提供する。

### クリック演出

- サイト本体表示後、画面クリック時に絵文字スパークを表示する。

## データ永続化要件

ブラウザの `localStorage` を使用して以下を保存する。

- `alohaz_diary_comments`: 交換日記コメント
- `alohaz_last_draw_date`: 最終ガチャ抽選日
- `alohaz_today_fortune`: 当日のガチャ結果
- `alohaz_gacha_collection`: 収集済み運勢レベル
- `alohaz_visitor_name`: コンプリートレター宛名
- `alohaz_firestore_photos`: Firebase フォールバック用フォトデータ
- `alohaz_firestore_diaries`: Firebase フォールバック用日記データ
- `alohaz_firestore_announcements`: Firebase フォールバック用お知らせデータ
- `alohaz_firestore_fortunes`: Firebase フォールバック用ガチャデータ
- `alohaz_firestore_letters`: Firebase フォールバック用手紙データ
- `alohaz_firestore_daily_stats`: Firebase フォールバック用日次統計

Firestore を使用できる環境では、以下のコレクションに公開/管理データを保存する。

- `photos`: フォトアルバムの写真
- `diaries`: 交換日記
- `announcements`: お知らせ
- `fortunes`: 管理対象のおみくじ結果
- `letters`: コンプリート手紙
- `daily_stats`: 日次統計
- `admins`: 管理者 UID
- `users/{uid}/gacha/state`: ファンごとのガチャ保存状態

## 非機能要件

- React と Vite で動作するシングルページアプリケーションとする。
- Tailwind CSS v4 を利用してスタイルを構築する。
- アニメーションには `motion` を利用する。
- アイコンには `lucide-react` を利用する。
- 効果音と音楽は Web Audio API で生成する。
- ガチャ演出には `canvas-confetti` を利用する。
- Firebase SDK を利用して Authentication と Firestore に接続する。
- レスポンシブ対応を行い、スマートフォンからデスクトップまで閲覧できる。
- Firebase Authentication では Google ログインに加えて匿名ログインを有効化する必要がある。

## 現状の制約

- SNSリンクは公式 URL 設定済みである。
- 動画再生は YouTube iframe 埋め込みである。
- ギャラリー画像と動画サムネイルの一部は `picsum.photos` の外部画像である。
- コメントは Firestore に保存される共有掲示板である。Firestore が使えない場合はローカルフォールバックで動作する。
- ガチャ記録は匿名アカウント単位で保存されるが、匿名アカウントを削除した場合や別端末への明示的な引き継ぎは現状未対応である。
- 管理画面は Firebase 認証と Firestore 連携を前提とするが、ローカルフォールバックでも動作する。
- 管理画面のガチャ結果、手紙データは公開側にも反映される。
- `/admin` 切り替えは `window.location.pathname` と History API による簡易ルーティングである。
- `firebase-applet-config.json` はクライアント Firebase 設定であり、アクセス制御は Firestore ルールで担保する。
- ファンコメントの moderation 機能は実装されていない。
